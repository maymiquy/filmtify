# Filmtify: Your Ultimate Streaming Destination

Filmtify is a cutting-edge streaming platform that offers an unparalleled viewing experience for movie enthusiasts. Designed to cater to the diverse tastes of our subscribers, Filmtify provides access to a vast library of high-quality films, catering to a wide range of genres and interests.

## Feature Spec

#### Subscription Plans

Filmtify offers three distinct subscription plans to suit your preferences:

1. **Basic Plan**:

   - Unlimited access to the entire movie library
   - Daily viewing limit of 3 movies
   - Rp. 9.000 per month

2. **Premium Plan**:

   - Unlimited access to the entire movie library
   - Daily viewing limit of 15 movies
   - Rp. 19.000 per month

3. **Platinum Plan**:
   - Unlimited access to the entire movie library
   - Unlimited viewing limits
   - Early access to select films
   - RP. 29.000 per month

#### Authentication

1. **Regular Auth**:
   - Basic credential login
   - Basic credential register
2. **OAuth 2.0**:
   - Google credential login
   - Google credential register
   - Facebook credential login
   - Facebook credential register

#### Core feature

1. **Streaming**:
   - Video Player
   - Control Player
2. **Collection**:
   - User can add movie to collection
   - User can delete movie in collection
   - User can organize movie category to pop up
